# Sports Statistics AI Agent

An intelligent, autonomous sports analytics application built with **Streamlit**, **LangChain**, and **Google Gemini 3.5 Flash**. The agent dynamically analyzes CSV/Excel sports datasets (Cricket, Football, Basketball, etc.), automatically detects the sport type, provides role-specific query recommendations, executes complex pandas calculations, and generates charts on-demand.

---

## Key Features

* **Automatic Sport Detection**: Automatically detects the sport type (Cricket, Football, Basketball, or General Sports) from column names and dataset entries.
* **Role-Based Analysis & Presets**: Select specific positions (e.g., Batter, Bowler, Forward, Midfielder, Guard) to receive tailored, high-value suggested analytical questions.
* **Natural Language Querying**: Ask freeform questions about player rankings, team aggregates, head-to-head comparisons, efficiency metrics, or custom statistics.
* **Automated Chart Generation**: Built-in plotting tool executes custom Matplotlib & Seaborn code to produce visual charts directly embedded into the response.
* **Custom Pandas Code Execution**: Computes advanced sports metrics (e.g., Strike Rate, Economy, xG, PER, Goals per 90) using secure Pandas execution.
* **Interactive Data Explorer**: View total rows, columns, data types, missing values, and dataset previews inside a collapsible Streamlit section.

## Getting Started

### 1. Prerequisites

* Python 3.10+
* A Google Gemini API Key ([Get an API key here](https://aistudio.google.com/))

### 2. Environment Setup

Clone or navigate to the project folder:

```bash
cd sports_statistics_ai_agent
```

Create a virtual environment and activate it:

```bash
python3 -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

### 3. API Key Configuration

Create or edit the `.env` file in the root directory and add your Google Gemini API key:

```env
GOOGLE_API_KEY=your_gemini_api_key_here
```

---

## Running the Application

Launch the Streamlit interface:

```bash
streamlit run app.py
```

Open your browser at `http://localhost:8501`.

## How It Works

1. **Upload Dataset**: Upload any Cricket, Football, Basketball, or General Sports dataset in `.csv`, `.xlsx`, or `.xls` format.
2. **Auto Detection**: The app inspects your schema and flags the detected sport.
3. **Filter by Role**: Choose a role/position filter to get contextual preset questions.
4. **Ask Questions**: Select a preset query or type a custom question (e.g., *"Who are the top 5 goal scorers?"* or *"Plot a chart comparing the top 5 batters by runs"*).
5. **Get AI Insights & Charts**: View detailed Markdown commentary and automatically embedded charts generated by the agent.

## Available Agent Tools

| Tool Name             | Description                                                                                   |
| --------------------- | --------------------------------------------------------------------------------------------- |
| `dataset_info`        | Returns dataset dimensions, columns, dtypes, and preview rows.                                |
| `missing_values`      | Checks count of null/missing values per column.                                               |
| `summary_statistics`  | Provides statistical summaries for numerical and categorical fields.                          |
| `player_stats_lookup` | Performs case-insensitive lookup for specific player records.                                 |
| `team_stats_summary`  | Aggregates team metrics and numeric breakdowns.                                               |
| `match_analysis_tool` | Head-to-Head comparison between two players or teams.                                         |
| `find_best_players`   | Ranks top-N players based on any metric (Runs, Wickets, Goals, xG, PTS).                      |
| `run_pandas_code`     | Safely executes Pandas python code for custom metrics and complex filtering.                  |
| `plot_chart`          | Executes Matplotlib/Seaborn code, saves the image to `charts/`, and returns path for display. |
